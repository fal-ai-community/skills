# Branded graphics

A finished branded graphic includes the required brand assets and copy at the
requested dimensions. A generated background can be an intermediate asset.

## Brand sources and output

Use supplied brand files or the brand's official site for the logo, palette,
type and approved copy. Do not infer brand colors from the company name or a
model's output. Keep the original logo's shape, proportions and clear space.
If a complete logo or wordmark SVG exists, place that asset intact. Do not
rebuild its lettering with a font.
If a required asset is inaccessible, identify the missing asset instead of
inventing it or claiming a complete result.

Honor the requested dimensions, format and safe areas. When the brief names a
platform without dimensions, verify its current specifications. Do not add
unrequested slogans or change exact copy.
For a brand-only brief with no supplied copy, use the original logo or wordmark
without extra claims or slogans. A phrase from memory is not approved brand copy.

## Choose the method

Use the simplest method that satisfies the brief with the tools available.

- For exact logos, typography or layout, code composition keeps those assets
  intact. A text-free generated background plus original logo and real text is
  one useful approach. SVG, HTML with a raster export, or a raster compositor
  can all work. Pure composition needs no model call.
- A model can produce a complete graphic when its reference inputs and output
  quality meet the brief. Check the actual result for logo drift and text errors.
- For a background-only request, deliver the background. Do not add a logo or
  copy that the user excluded.

Use current model guidance and the endpoint's actual input contract for any
generation. Preserve the user's model choice and existing authorization.
Do not assume the client has code execution, a browser or a particular renderer.
If required tools are absent, explain the remaining step and deliver only what
you can verify.

## Verify and deliver

Inspect the final rendered image, including exact copy, logo fidelity, palette,
legibility, cropping and safe areas. Read the exported file's dimensions and
format. Check font and image loading when a browser renders the composition.
Repair observed defects within the authorized scope; avoid speculative reruns.

Deliver the finished image in the requested format. Include editable source when
requested or useful. An HTML source file or a preview link alone does not replace
a requested PNG. State any checks that remain unverified.
