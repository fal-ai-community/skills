# fal media tools

Use the connected fal MCP server when the user chooses fal. Preserve another
explicitly chosen provider. Activate the bundled skills only for the requested
creative task. Follow `fal-media` for MCP discovery, pricing, uploads and jobs.

The bundle uses browser OAuth with the user's fal account. It needs no API key
in a manifest. Generation consumes that account's credits. Preserve the user's
budget and approvals. Do not generate media merely to test installation.

The default bundle includes `fal-media` and five outcome guides. Load specialist
instructions through search_guidance and read_guidance when the task needs them.
Use recommend_model for current model choices, then inspect schemas and prices.
The complete library remains in https://github.com/fal-ai-community/skills.
No CLI, local renderer or composition runtime is installed by this extension.
Verify local tools before promising assembled films, captions or sprite atlases.
